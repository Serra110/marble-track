
# Marble Track 

A simple marble track that I designed in Onshape.

## Features

- Curved track sections
- A Plinko board
- A funnel
- A staircase
- A marble

## How It Works

The marble starts on the straight section of the track and travels through the curves before falling into the funnel,then enters the Plinko board, bouncing through the pegs until it exits and continues down the track. Finally, it enters the staircase and rolls down to the bottom, where it is collected.

## 3D Printing Information

I plan to print this using the following settings:

- **Material:** Standard PLA
- **Infill:** 15-20%
- **Layer Height:** Standard
- **Supports:** Automatic supports

I recommend using **tree supports** to avoid interfering with the track sections. They should also be a more cost-effective option than other viable support configurations while maintaining stability.
