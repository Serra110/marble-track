# marble-track
A simple marble track that I made in onshape
It includes:
- Curves
- A plinko
- A funnel
- A staircase
- It starts in the straight part of the track, then goes to the curves, then falls to the funnel, after that it goes to the plinko and leavesm, going don and entering the stairs, then it ends there
